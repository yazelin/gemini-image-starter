# 繪圖魔法師入門:工作坊與顧問協助

這個 repo 的教學內容會盡量公開,讓你可以自己照著做。

如果你需要的不是「看文件」,而是希望有人陪你把它改成自己的情境,可以考慮工作坊或顧問協助。

## 適合找我協助的情況

- 你照 README 做但卡在 `GEMINI_API_KEY`、拿不到圖、或結果不可控的問題。
- 你想把結構化 prompt 改成公司內部流程(品牌貼圖、商品圖、角色設計)。
- 你需要幫客戶或老闆做一個能展示的生圖 PoC。
- 你想知道這套範例上線前還缺哪些設計(額度控管、批次、圖生圖、成本)。
- 你想用這個題目規劃內訓或小班課程。

## 可以提供的形式

- 2 小時線上工作坊。
- 小班陪跑與 Q&A。
- 一對一 debug / code review。
- 公司 PoC 需求訪談與架構建議。
- 協助把生圖流程部署到 VPS、雲端平台或公司內網。
