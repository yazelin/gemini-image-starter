AI 生圖入門

用 AI 生圖,把每次都隨機變成可控

用 Google Gemini 學 AI 生圖入門:從一句話 prompt,到結構化、可控、可重現的 prompt 設計。

「a cat」每次生出來都不一樣 —— 姿勢、畫風、背景、光線全是模型替你決定的。要拿來做產品(貼圖、頭像、角色)時,這種隨機就是痛點。把決定權拿回來的,是 prompt 設計。

Gemini / structured prompt / 可重現台灣繁中向Gemini Image Starter

這個範本解決什麼?

  • Part 1:一句話 prompt「a cat」,看清「每次都不一樣」的痛點
  • Part 2:結構化 prompt(主體 / 風格 / 光線 / 構圖 / 配色 / 負面詞)→ 可控、可重現
  • 核心魔法是 prompt 設計,不是某個按鈕
  • gen client 對齊真實 Gemini API,base_url 可注入
  • 免 API key 的確定性測試:勾完 prompt 邏輯與請求形狀再去燒額度
